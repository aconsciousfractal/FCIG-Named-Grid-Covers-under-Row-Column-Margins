# Release review checklist

## Package and paths

- [ ] No absolute drive path, private-repository dependency, symlink, or
  escaping path.
- [ ] README, paper, claim ledger, source lock, and manifest agree on scope.
- [ ] License scope and third-party notices cover every shipped class of file.
- [ ] Git remote, tag, release metadata, and checksums agree.

## Mathematics and paper

- [ ] Definitions distinguish support, purity, repair, `G_E^(2)`, and
  `G_E^(<=2)`.
- [ ] Translation cap contains the empty branch.
- [ ] Active-carrier and FPT hypotheses include the finite cell list, selected
  set, largest-piece rule, residual area `q`, and orientation bound `h`.
- [ ] Type compression is separated from literal output enumeration.
- [ ] Energy descent remains sufficient rather than necessary.
- [ ] C32/C46/P49 counts, roles, and source attribution agree with certificates.
- [ ] P21 fixed-fiber, lattice, and all-RHS Markov claims remain distinct.
- [ ] Exact Markov degree and complete basis remain open.

## Reproducibility

- [ ] Supported CPython range and exact dependency preflight pass.
- [ ] Manifest profile passes without changing frozen bytes.
- [ ] Core and full profiles pass.
- [ ] Mutation suites pass.
- [ ] Source and release checksum manifests pass.
- [ ] Title-named PDF rebuilds and the manuscript verifier passes.
- [ ] Every rendered PDF page is visually inspected.
- [ ] No unresolved high-severity package or scope defect remains.
